01 / {% if lang == 'ur' %}بنیادی معلومات{% else %}Understanding the condition{% endif %}

{% if lang == 'ur' %}پارکنسنز کی بیماری کیا ہے؟{% else %}More than just a movement disorder{% endif %}

{% if lang == 'ur' %}یہ ایک آہستہ بڑھنے والی اعصابی بیماری ہے۔ اس سے حرکت کے ساتھ نیند، مزاج اور روزمرہ زندگی بھی متاثر ہو سکتی ہے۔{% else %}Parkinson's is a progressive neurological condition. It commonly affects movement, but it can also influence sleep, mood and everyday wellbeing.{% endif %}

{% if lang == 'ur' %}دماغ میں کیا تبدیلی آتی ہے؟{% else %}What happens inside the brain?{% endif %}

{% if lang == 'ur' %}دماغ کے بعض اعصابی خلیے جو ڈوپامین پیدا کرتے ہیں بتدریج کم ہوتے جاتے ہیں۔ ڈوپامین ہموار اور منظم حرکت میں مدد دیتا ہے۔ اس کی کمی سے حرکت میں سستی، اکڑن یا کپکپاہٹ جیسی علامات ظاہر ہو سکتی ہیں۔{% else %}Certain nerve cells that produce dopamine gradually become lost. Dopamine helps the brain control smooth, coordinated movement. Lower dopamine levels can contribute to symptoms such as slowness, stiffness and tremor.{% endif %}

{% if lang == 'ur' %}ہر شخص مختلف ہے{% else %}Every experience is different{% endif %}

{% if lang == 'ur' %}ہر مریض کو ایک جیسی علامات نہیں ہوتیں اور بیماری کی رفتار بھی مختلف ہوتی ہے۔{% else %}People experience different symptoms, and the condition progresses at different rates.{% endif %}

{% if lang == 'ur' %}تشخیص ڈاکٹر کرتا ہے{% else %}Diagnosis is clinical{% endif %}

{% if lang == 'ur' %}صرف کپکپاہٹ، چلنے کے انداز یا اے آئی اسکریننگ سے تشخیص نہیں ہو سکتی۔{% else %}Neither a symptom nor an AI screening result can confirm Parkinson's on its own.{% endif %}

{% if lang == 'ur' %}زندگی بہتر بنائی جا سکتی ہے{% else %}Living well is possible{% endif %}

{% if lang == 'ur' %}ادویات، تھراپی، ورزش اور مناسب مدد سے بہت سے افراد کو فائدہ ہوتا ہے۔{% else %}Medication, therapy, exercise and supportive care can help people manage symptoms.{% endif %}

02 / {% if lang == 'ur' %}ابتدائی علامات{% else %}Signs & symptoms{% endif %}

{% if lang == 'ur' %}کن علامات پر توجہ دینی چاہیے؟{% else %}The signs worth knowing{% endif %}

{% if lang == 'ur' %}علامات آہستہ ظاہر ہو سکتی ہیں، کبھی جسم کے ایک طرف زیادہ نمایاں ہوتی ہیں۔ صرف ایک علامت ہونے کا مطلب پارکنسنز نہیں ہے۔{% else %}Signs may appear gradually and can be more noticeable on one side of the body. Having one symptom alone does not mean someone has Parkinson's.{% endif %}

{% if lang == 'ur' %}آرام میں کپکپاہٹ{% else %}Tremor at rest{% endif %}

{% if lang == 'ur' %}آرام کے وقت ہاتھ یا انگلی میں غیر ارادی لرزش۔{% else %}Shaking that may affect the hands or fingers while resting.{% endif %}

{% if lang == 'ur' %}حرکت میں سستی{% else %}Slower movement{% endif %}

{% if lang == 'ur' %}چلنے، اٹھنے یا کپڑے پہننے جیسے کام زیادہ وقت لینا۔{% else %}Routine activities such as walking or getting dressed take longer.{% endif %}

{% if lang == 'ur' %}چال میں تبدیلی{% else %}Changes in walking{% endif %}

{% if lang == 'ur' %}چھوٹے قدم، پاؤں گھسیٹنا یا بازو کم ہلنا۔{% else %}Shorter steps, shuffling feet or reduced arm swing.{% endif %}

{% if lang == 'ur' %}آواز کا مدھم ہونا{% else %}Voice changes{% endif %}

{% if lang == 'ur' %}آواز نرم یا کم واضح ہونا، یا لہجے میں تبدیلی۔{% else %}Speech becomes softer, less clear or less expressive.{% endif %}

{% if lang == 'ur' %}اکڑن اور توازن{% else %}Stiffness & balance{% endif %}

{% if lang == 'ur' %}پٹھوں میں سختی، مڑنے میں دقت یا عدم توازن۔{% else %}Muscle stiffness, difficulty turning or problems with balance.{% endif %}

{% if lang == 'ur' %}حرکت سے ہٹ کر علامات{% else %}Beyond movement{% endif %}

{% if lang == 'ur' %}نیند، سونگھنے کی حس، قبض یا مزاج میں تبدیلی۔{% else %}Changes in sleep, smell, digestion or mood can also occur.{% endif %}

{% if lang == 'ur' %}یاد رکھیں{% else %}An important reminder{% endif %}

{% if lang == 'ur' %}ایسی علامات کئی دیگر وجوہات سے بھی ہو سکتی ہیں۔ اگر علامات برقرار رہیں یا بڑھیں تو طبی معائنہ کروائیں۔{% else %}Many of these changes have causes other than Parkinson's. If symptoms persist or worsen, speak with a healthcare professional.{% endif %}

03 / {% if lang == 'ur' %}خطرے کے عوامل{% else %}Understanding risk{% endif %}

{% if lang == 'ur' %}پارکنسنز کا خطرہ کن عوامل سے بڑھ سکتا ہے؟{% else %}What can increase the risk?{% endif %}

{% if lang == 'ur' %}خطرے کے عوامل کا تعلق بیماری کے امکان سے ہے، لیکن یہ یقینی پیش گوئی نہیں کرتے۔{% else %}Risk factors are associations—not predictions. Having one or several does not mean a person will develop Parkinson's.{% endif %}

{% if lang == 'ur' %}خطرہ جاننا، تشخیص نہیں{% else %}Risk is not a diagnosis.{% endif %}

{% if lang == 'ur' %}آپ کے سوالات اہم ہیں، لیکن بیماری کی تشخیص طبی معائنے سے ہی ممکن ہے۔{% else %}Understanding the factors can help guide informed conversations—not determine whether you have the disease.{% endif %}

{% if lang == 'ur' %}قریبی رشتہ دار میں بیماری ہونا خطرہ بڑھا سکتا ہے۔{% else %}Having a close family member with Parkinson's may increase risk.{% endif %}

03

{% if lang == 'ur' %}ماحولیاتی عوامل{% else %}Environmental exposures{% endif %}

{% if lang == 'ur' %}بعض کیڑے مار ادویات اور آلودگی سے تعلق پایا گیا ہے۔{% else %}Some pesticides and environmental exposures are associated with risk.{% endif %}

04

{% if lang == 'ur' %}جینیاتی عوامل{% else %}Genetic factors{% endif %}

{% if lang == 'ur' %}کچھ جینیاتی تبدیلیاں اہم ہیں، لیکن اکثر ایک ہی وجہ نہیں ہوتی۔{% else %}Certain gene variants contribute, but most cases have no single known cause.{% endif %}

04 / {% if lang == 'ur' %}دیکھ بھال اور علاج{% else %}Treatment & everyday care{% endif %}

{% if lang == 'ur' %}مناسب علاج سے زندگی بہتر ہو سکتی ہے{% else %}Support makes a meaningful difference{% endif %}

{% if lang == 'ur' %}فی الحال بیماری کو مکمل طور پر ختم کرنے والا علاج دستیاب نہیں، لیکن مختلف طریقوں سے علامات کو سنبھالا جا سکتا ہے۔{% else %}There is currently no cure for Parkinson's, but treatments and supportive strategies can help manage symptoms and support quality of life.{% endif %}

{% if lang == 'ur' %}ادویات اور معائنہ{% else %}Medical treatment{% endif %}

{% if lang == 'ur' %}ڈاکٹر کی تجویز کردہ ادویات، مثلاً لیووڈوپا، بعض حرکتی علامات کم کر سکتی ہیں۔ دوا صرف ڈاکٹر کے مشورے سے لیں۔{% else %}Clinician-prescribed medicines, including levodopa-based treatments, can help with movement symptoms. Do not adjust medication without medical guidance.{% endif %}

{% if lang == 'ur' %}جسمانی ورزش اور فزیوتھراپی{% else %}Movement & physiotherapy{% endif %}

{% if lang == 'ur' %}مناسب ورزش، توازن کی مشقیں اور فزیوتھراپی حرکت اور روزمرہ کاموں میں مدد دے سکتی ہیں۔{% else %}Suitable physical activity and physiotherapy may help with mobility, balance and everyday function.{% endif %}

{% if lang == 'ur' %}آواز اور روزمرہ مدد{% else %}Speech & daily support{% endif %}

{% if lang == 'ur' %}اسپیچ تھراپی، گھر میں حفاظت، اور خاندان کی مدد بھی مفید ہو سکتی ہے۔{% else %}Speech therapy, practical home-safety changes and support from family or carers can make daily life easier.{% endif %}

{% if lang == 'ur' %}بہترین منصوبہ ہر شخص کی ضرورت کے مطابق مختلف ہوتا ہے۔ علامات، ادویات اور ورزش کے بارے میں ماہرِ صحت سے مشورہ کریں۔{% else %}The most appropriate care plan is individual. A qualified healthcare professional can help tailor treatments and activity to specific needs.{% endif %}

05 / {% if lang == 'ur' %}اگلا قدم{% else %}Taking action{% endif %}

{% if lang == 'ur' %}اگر آپ کو علامات محسوس ہوں تو کیا کریں؟{% else %}Noticing changes? Here's what to do.{% endif %}

{% if lang == 'ur' %}ابتدائی آگاہی اور مناسب طبی مشورہ اہم ہیں۔ اپنی علامات کو نظر انداز نہ کریں۔{% else %}A few practical steps can help you describe your concerns clearly and receive appropriate medical advice.{% endif %}

01

{% if lang == 'ur' %}تبدیلیوں کا ریکارڈ رکھیں{% else %}Keep track of changes{% endif %}

{% if lang == 'ur' %}علامات کب شروع ہوئیں، کتنی بار ہوتی ہیں اور روزمرہ زندگی کو کیسے متاثر کرتی ہیں، نوٹ کریں۔{% else %}Write down when symptoms began, how often they occur and whether everyday activities are affected.{% endif %}

02

{% if lang == 'ur' %}طبی معائنہ کروائیں{% else %}Speak with a clinician{% endif %}

{% if lang == 'ur' %}ڈاکٹر آپ کا جائزہ لے سکتا ہے اور ضرورت پڑنے پر نیورولوجسٹ سے رجوع کرنے کا کہہ سکتا ہے۔{% else %}A healthcare professional can assess your symptoms and refer you to a neurologist when appropriate.{% endif %}

03

{% if lang == 'ur' %}مناسب فالو اَپ کریں{% else %}Agree on next steps{% endif %}

{% if lang == 'ur' %}ڈاکٹر کی ہدایات کے مطابق مزید جانچ، علاج یا تھراپی پر عمل کریں۔{% else %}Discuss appropriate evaluation, follow-up and treatment or rehabilitation if needed.{% endif %}

{% if lang == 'ur' %}فوری توجہ والی علامات{% else %}Know what needs urgent attention{% endif %}

{% if lang == 'ur' %}اچانک کمزوری، چہرہ ٹیڑھا ہونا یا اچانک بولنے میں مشکل ہنگامی صورتحال ہو سکتی ہے۔ فوری طبی امداد حاصل کریں۔{% else %}Sudden weakness, facial drooping or sudden trouble speaking may be signs of a medical emergency such as stroke. Seek emergency care immediately.{% endif %}
